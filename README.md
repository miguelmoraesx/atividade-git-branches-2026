# Atividade prática de Git e GitHub

Repositório criado para a segunda atividade prática de Gerência de Configuração, com foco em comandos básicos, branches e sincronização com o GitHub.

## Objetivos

- inicializar e publicar um repositório;
- praticar `add`, `commit`, `push` e `pull`;
- criar, atualizar e integrar uma branch.
